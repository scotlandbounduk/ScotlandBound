How to use your map files

You do not need to edit the files. Download the files above first, then follow the guide for the navigation app you want to use.

Google Maps — KML file

The KML file contains the ScotlandBound locations as a map layer. Google requires KML files to be imported through Google My Maps; after importing, you can view the map through your Google account.

  1. Download ScotlandBound_GoogleMaps.kml using the button above.
  2. On a computer, open Google My Maps and sign in to your Google account.
  3. Choose Create a new map (or open an existing map you want to add the ScotlandBound layer to).
  4. In the map legend, click Add layer, then click Import.
  5. Upload the downloaded .kml file from your computer.
  6. Wait for the locations to load, then give the map a name such as ScotlandBound.
  7. Open the map later from Google My Maps or view your saved My Maps through Google Maps.
Important: The KML is a map layer, not a turn-by-turn navigation route. Google My Maps is the place where you import the KML; the regular Google Maps app does not provide a direct KML-import button.
Sygic — 90 Favourite destinations

The Sygic download is not a GPX route. It is a ready-made Sygic places-database containing all 90 ScotlandBound stops as individual Favourite destinations.

  1. Install or update Sygic GPS Navigation on your phone and make sure the Scotland/UK map data you need is downloaded for offline use.
  2. Download the places-database file using the button above.
  3. Open Dropbox on the device (or access the Dropbox account you use for Sygic backups).
  4. Open the Sygic backup area: Apps → Sygic → DVv20plus.
  5. Locate the existing places-database file. Keep a copy of the original first if you already have personal Sygic Favourites you do not want to lose.
  6. Replace the existing places-database with the ScotlandBound file you downloaded. Keep the filename exactly as places-database.
  7. Open Sygic and use its Dropbox Backup & Restore function to restore the Sygic data from Dropbox.
  8. After the restore completes, open Menu → Favourites. The ScotlandBound stops should appear as individual Favourite destinations.
Important: This database is intended for Sygic GPS Navigation, not Sygic Truck Navigation. If you already have your own Sygic Favourites, back up the existing places-database before replacing it. The exact Dropbox wording or menu labels may vary slightly between Sygic versions.
Which one should I use?
Use Google Maps if you want the ScotlandBound locations displayed as a map layer. Use Sygic if you want the 90 locations available as individual Favourite destinations inside an offline navigation app. You can use both.
